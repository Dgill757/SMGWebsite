GAP 7: SET UP GHL WEBHOOK (5 minutes)
====================================================
This wires GHL to send reply events to your dashboard in real-time.
Every time a contact replies, the dashboard updates instantly.

STEPS:
1. Log into GHL: https://app.gohighlevel.com
2. Make sure you're in the Summit Voice AI sub-account (location: u1lprxdJy1vmuaHEVJRM)
3. Click Settings (gear icon, bottom left)
4. Click "Integrations" in the left sidebar
5. Click "Webhooks" tab at the top
6. Click "+ Add Webhook" (top right button)
7. Fill in:
   - Webhook Name: Ava Studio API
   - Webhook URL: https://ava-studio-api-production.up.railway.app/webhooks/ghl
   - Events to subscribe (check ALL of these):
     ✅ InboundMessage
     ✅ OutboundMessage
     ✅ ContactCreate
     ✅ AppointmentCreate
     ✅ OpportunityCreate
     ✅ OpportunityStatusChange
     ✅ NoteCreate
     ✅ TaskCreate
8. Click Save / Create Webhook
9. Done ✅

WHAT THIS DOES:
- Every time a contact replies to an outreach email/SMS, GHL fires this webhook
- The Ava Studio API receives it, classifies intent (POSITIVE/NEGATIVE/NONE)
- Dashboard updates in real-time — hot leads appear instantly
- You see every reply in the dashboard without checking GHL manually
