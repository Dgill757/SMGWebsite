SUMMIT OS — HOW TO USE IT IN 3 MINUTES
=======================================

OPEN EVERY MORNING (5 min total):
1. Slack → #ava-dispatch (morning brief is there at 7am — stats, hot leads, todo)
2. Browser → https://ava-demo-studio-dan-gill-iiis-projects.vercel.app
   Password: summit2026
3. Check "Replies" tab → any hot leads since yesterday?
4. Check Calendly / Google Calendar → calls booked for today?

That's it. Everything else runs without you.

COMMANDS (from dashboard search bar or Slack #ava-dispatch)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  build [website URL]
  → Builds a full demo in ~3-5 min. Deploys to Vercel. Sends email + SMS.
  → Example: build peakroofingdallas.com

  demo [website URL]
  → Same as build. 10 automated steps. Professional site + voice AI.

  audit [website URL]
  → Marketing audit only. No website build. ~60 seconds.

  scrape [City ST]
  → Triggers Apollo to find roofing owners in that city right now.
  → Example: scrape Dallas TX

  /status
  → Full system health check. All 7 scripts + Railway + Vercel.

You get:
  → Slack notification in #ava-dispatch
  → Desktop toast alert (if reply monitor is running — it checks every 15 min)
  → "Peak Roofing LLC" appears in dashboard Replies tab

Your options:
  A) Demo workflow fires automatically if "audit requested" tag was set
  B) Tap "Build Demo" button in dashboard → demo in ~3-5 min
  C) Type: build [their website URL] in Slack or dashboard

  → Contact field ava_demo_url is updated
  → Pipeline stage moves to "Demo Sent"

IF SOMETHING BREAKS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Railway down?
  → cd C:\Users\DanGi\Downloads\SummitVoiceAiWorkflowsandDemoMachine
  → railway up

  Script not running?
  → Task Scheduler → find "Summit*" task → right-click → Run
  → Check C:\Users\DanGi\scripts\*.log for errors

  Demo builds failing?
  → Check Railway logs: railway logs (or railway.com → your project → Logs)
  → Most common cause: Firecrawl can't scrape the site (Cloudflare-protected)
  → Fix: try a different website URL, or build with no website using the no-website path

  GHL workflows not firing?
  → GHL → Automation → check workflow is Published (not Draft)
  → Check the trigger condition matches what you expect
