2026 Animation Library Stack — Your Arsenal

This is your complete 2026 animation toolkit for roofing websites. Each library has a specific job — use the right one for the right effect.

GSAP + ScrollTrigger
King of Scroll Animations 60fps Guaranteed Free for most projects
The undisputed #1 for scroll-driven, timeline-sequenced animations. ScrollTrigger pins sections as you scroll, creates parallax layers, staggered element reveals, and cinematic scroll stories. Works with Three.js objects, SVG, CSS, and canvas. 23KB core + 7KB ScrollTrigger.
✅ ROOFING USE: Hero text reveals, before/after gallery scroll pins, service card stagger animations, scroll-triggered number counters, pinned "Our Process" sections
Framer Motion
React Native Layout Animations Exit Animations
Built for React — handles component mounting/unmounting animations, shared layout transitions, drag interactions, and gesture-based animations. Simpler API than GSAP for React projects. Best for UI-level micro-interactions: modals, dropdowns, tabs, card hovers.
✅ ROOFING USE: Quote form modal animations, service tab transitions, mobile nav open/close, testimonial card interactions, before/after slider drag gesture
Three.js
WebGL / 3D High Complexity Max Impact
Full 3D WebGL renderer. Creates floating 3D roofing material models, interactive particle systems, animated building cross-sections, spinning shingle displays. Combine with GSAP ScrollTrigger to sync 3D camera movement to scroll position — this is what creates $30K-looking sites.
✅ ROOFING USE: Hero background particle storm, 3D roof cross-section reveal on scroll, floating material samples (shingles, metal panels), animated before/after 3D transition
Spline
No-Code 3D React Embed Free tier available
Design 3D scenes in a visual editor, then embed with @splinetool/react-spline. No WebGL code required. Perfect for creating a realistic spinning roof or house model for the hero. The client sees a 3D house rotating in the background — built in Spline in 20 minutes, embedded in 5.
✅ ROOFING USE: Hero rotating 3D house model, interactive 3D roof section for the "Our Process" page, animated logo reveal, material type selector in 3D
Lenis (Smooth Scroll)
Smooth Scroll Pairs with GSAP 2KB
Replaces native browser scroll with buttery-smooth momentum scroll. Combine with GSAP ScrollTrigger for the "premium agency" feel. The difference is immediately noticeable — your site feels like a $30K site the moment someone starts scrolling.
✅ ROOFING USE: Every site. Install by default. Instant premium feel upgrade with 4 lines of code.
React Three Fiber (R3F)
Three.js for React Declarative 3D Production Ready
React wrapper for Three.js. Write 3D scenes as JSX components instead of imperative Three.js code. Dramatically reduces complexity. Pair with Drei (helper components) for instant access to orbit controls, environment maps, shadow maps, and 3D text.
✅ ROOFING USE: When building in React/Next.js and want 3D without raw Three.js complexity. Use Spline for simple scenes, R3F for custom interactive 3D.

Scroll Effects — The Signature of Premium Sites

Lenis + GSAP Setup (Copy This Into Every Project)
src/lib/scroll-setup.ts — paste this into every roofing project
import Lenis from 'lenis'; import gsap from 'gsap'; import { ScrollTrigger } from 'gsap/ScrollTrigger'; import { SplitText } from 'gsap/SplitText'; // Premium plugin gsap.registerPlugin(ScrollTrigger, SplitText); // Initialize Lenis smooth scroll const lenis = new Lenis({ duration: 1.2, easing: (t) => Math.min(1, 1.001 - Math.pow(2, -10 * t)), orientation: 'vertical', smoothWheel: true, }); // Sync Lenis with GSAP ticker gsap.ticker.add((time) => { lenis.raf(time * 1000); }); gsap.ticker.lagSmoothing(0); // Connect Lenis to ScrollTrigger lenis.on('scroll', ScrollTrigger.update); export { lenis };
Scroll-Triggered Text Reveal (SplitText)
Headline reveal — GSAP SplitText
// Splits headlines into individual chars and stagger-animates them in // This is the effect you see on every Awwwards site const heroHeadline = document.querySelector('.hero-headline'); const split = new SplitText(heroHeadline, { type: 'chars,words' }); gsap.from(split.chars, { opacity: 0, y: 80, rotationX: -90, stagger: 0.02, duration: 0.8, ease: 'back.out(1.5)', scrollTrigger: { trigger: heroHeadline, start: 'top 80%', } }); // For section headings — word-by-word reveal gsap.from(split.words, { opacity: 0, y: 40, stagger: 0.08, duration: 0.6, ease: 'expo.out', scrollTrigger: { trigger: heroHeadline, start: 'top 85%' } });

Starting a New Project — The Exact Workflow

🎯
Always start in VS Code with Claude Code — not in claude.ai. Claude Code has file system access, can run bash commands, install packages, and deploy. Claude.ai is for conversations, not builds. Use Cursor (VS Code + Claude Code) as your primary IDE.

Decision Tree: Which Build Path?

Path A: Clone + Customize Fastest (45 min)
Client has a good reference site they like, or you found a premium roofing site to clone and rebrand. Uses JCodesMore cloner.
Best for: "Make it look like THIS but for our company"
Path B: Build from Foundation Best Quality (90 min)
Use the master foundation prompt + section-by-section build. Maximum control, best animations, most customizable result.
Best for: Premium builds, new clients, custom 3D effects

1
Research (10 min)

Launch Clone Session (5 min)

3
Clone the Reference Site (5-10 min)
Inside Claude Code terminal: /clone-website https://[REFERENCE_SITE].com — Claude opens Chrome, screenshots every section, extracts components, and generates your editable React codebase. Use Sonnet 4.6 to keep cost at $4-9.

Client-Swap Variables (5 min)
Open constants.ts (or wherever company info is stored). Replace: company name, phone, city, service areas, certifications, colors if different. The JCodesMore cloner usually creates a central config — find it with grep -r "COMPANY" src/

Layer in Animations (20-30 min)
Now prompt Claude section by section: "Add GSAP ScrollTrigger reveal animations to all section headings." / "Add Lenis smooth scroll." / "Add the magnetic button effect to all CTAs." Use the prompts from the Animation Prompts section of this guide.

Deploy Preview to Vercel (2 min)
git add . && git commit -m "initial build" && git push → Vercel auto-deploys via GitHub. Share https://[client-name]-preview.vercel.app before they've paid a dime.
