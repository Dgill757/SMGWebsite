# Summit JARVIS desktop launcher

This opens the live SummitOS Jarvis tab in Microsoft Edge or Google Chrome app mode, without normal browser tabs or toolbars.

Install the desktop shortcut once:

```powershell
powershell -ExecutionPolicy Bypass -File .\desktop_jarvis\Launch-Summit-Jarvis.ps1 -InstallShortcut
```

After installation, double-click **Summit JARVIS** on the Windows desktop. Sign in with the same SummitOS access code.
